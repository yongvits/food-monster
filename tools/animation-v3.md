# Character animation v3

Generated with built-in imagegen, one sheet per hero. Runtime uses eight walk poses and eight run poses without optical-flow interpolation or pose cross-fading. `pack-strides.cjs` isolates the 16 largest connected silhouettes, packs safe transparent margins, and uses one scale per character. Source WebP files preserve the generated alpha.
