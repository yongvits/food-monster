# Food Monster

A side-scrolling browser game by Mushroom Studio.

Five worlds, five playable characters, original synthesized music, varied enemies and time-limited power-ups.

Run locally: `python -m http.server 8000 --directory dist`, then open http://localhost:8000.

Move: arrows / A / D. Jump: Space. Run: hold Shift. Pause: P / Escape. Mobile: on-screen touch controls.

Game files: dist/. Animation tools: tools/. No build step required.
